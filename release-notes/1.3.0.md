## Install

1. Open the download link **on your Android phone**. If the browser warns
   about the file, tap **Download anyway**.
2. Tap the finished download (or find `MatIQ-1.3.0-android.apk` in your
   **Files** / **Downloads** app).
3. If Android asks, allow installs from this source: **Settings → Allow from
   this source**, then go back.
4. Tap **Install**. If Play Protect says the developer is unknown, tap **More
   details → Install anyway**; you see this because MatIQ isn't on the Play
   Store yet.
5. Open **MatIQ**, tap **Create an account** and confirm your email from the
   same phone.

- **New logo and app icon**: a fighter with both arms raised, inside the
  cage. It also adapts to Android's themed icons.
- **Splash screen** with the MatIQ logo while the app starts.
- **New welcome screen** when you sign in.
